# Contributing

Open a PR with one line in the matching section:

```
- [name](url) - One sentence on what it does. Extra tags if they help choose.
```

- Alphabetical within a section.
- Prefer a working repo over a landing page.
- The entry should run a System One model, implement the request shape, or help evaluate, route, or compare them.
- Baselines and benchmarks are welcome when they make the comparison fairer, not just longer.

## The bar

This is a curated list, not an index — directories like awesomejev.com already track every Jev repo. An entry earns its slot when it does at least one of:

- Teaches a distinct pattern (a use of typed decisions we don't already show).
- Is the strongest example of its category (adoption, maintenance, or craft).
- Carries credible evidence (a real benchmark, published numbers, notable maintainer).

Skip it when:

- It's a variant of a pattern already covered (we don't need a third context pruner or a fifth browser agent).
- The Jev/System One usage is incidental rather than load-bearing.
- The repo is a stub, a joke, or claims numbers it doesn't back up.
