# Contributing

Open a PR with one line in the matching section:

```
- [name](url) - One sentence on what it does. Extra tags if they help choose.
```

- Alphabetical within a section.
- Prefer a working repo over a landing page.
- The entry should run a System One model, implement the request shape, or help evaluate, route, or compare them.
- Baselines and benchmarks are welcome when they make the comparison fairer, not just longer.
